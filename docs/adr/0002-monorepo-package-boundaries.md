# Monorepo package boundaries for `@cms/*`

**Superseded.** The one-way graph `fields → components → form → crud → routes → astro-template` remains a useful description of the **current** prototype layout, not a locked extraction target. Package names and the consumer install root must wait until the conceptual layers stabilize.

See [ADR-0009](0009-conceptual-layers-before-package-extraction.md).
