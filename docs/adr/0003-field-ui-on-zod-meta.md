# FieldUi rides on Zod `.meta()`, not collection siblings

Superseded by [ADR-0019](0019-cms-first-semantic-schema.md). Field UI, layout,
and semantic kinds are authored in the CMS unified tree; Astro schemas are
generated and no longer carry FieldUi on Zod `.meta()`.
